# DevConnect 🚀.

Full Stack DevOps Project using:
- React (Frontend)
- Node.js (Backend)
- MongoDB (Database)
- Docker
- Kubernetes
- AWS EC2

## Features
- User Authentication (JWT)
- Create & View Posts

## Run Locally

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start

## Docker
docker-compose up

## Kubernetes
kubectl apply -f k8s
